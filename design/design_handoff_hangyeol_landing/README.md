# Handoff: 한결 1차 오프라인 모임 랜딩 페이지

## 개요

한결(Hangyeol) 1차 오프라인 모임의 **소개 + 신청 랜딩 페이지**. 모바일 우선(명함 QR·인스타 유입), 데스크톱은 2열로 확장.
순백 배경 + 잉크 블랙 + 회색 단계만 사용하는 무채색 시스템에, 명조 계열 서체를 섞어 딱딱함을 덜었다.
히어로에 스크립트된 인트로 시퀀스(로고 획 → 하트 → 헤드라인 → 워드플레이)가 있고, 이후 섹션은 스크롤 진입 시 페이드업.

## 이 번들의 파일에 대해

`hangyeol-landing.dc.html`은 **디자인 레퍼런스**다 — 의도한 룩과 동작을 보여주는 HTML 프로토타입이며, 그대로 배포할 프로덕션 코드가 아니다.
할 일은 **이 디자인을 대상 코드베이스의 환경에서 다시 구현하는 것**이다. 아직 스택이 없다면(현재 한결 저장소는 코드 없음) 프레임워크를 먼저 정하고 그 환경의 관례대로 구현한다. 추천: **Next.js(App Router) + TypeScript + Tailwind CSS**, 폼은 서버 액션 또는 API Route + 시트/DB.

주의: 이 HTML은 Design Component 런타임(`support.js`)에 의존한다. 브라우저에서 열어 룩·타이밍을 확인하는 용도로만 쓰고, 마크업/스타일 값은 아래 스펙과 파일 내 인라인 스타일에서 읽어라. 로직 클래스(`class Component extends DCLogic`)는 파일 하단 `<script data-dc-script>` 안에 있다.

## 충실도

**하이파이(hifi)**. 색·타이포·간격·애니메이션 타이밍이 모두 확정값이다. 픽셀 단위로 재현할 것. 아직 비어 있는 것은 두 가지뿐: **행사 날짜**(현재 "날짜 미정" 자리표시), **운영자 사진 2장**(드롭 슬롯).

## 브랜드 · 톤 (반드시 지킬 것)

- 이름: 한결 — 슬로건 "결국에는 결이더라". 가치관·성격의 *결*이 맞는 사람을 오프라인에서 연결.
- 워드플레이: 한**결**+**같이**, "같이"와 "가치"가 같은 소리.
- **금지어**: "소개팅앱", "헌팅", 술자리를 연상시키는 표현. 과장 금지.
- 내부 용어(결카드, 로테이션, 매칭 유사도) 노출 금지.
- 사업자 정보 블록 없음. 결제는 이번 범위 밖 — **신청 폼까지만**.

### 스크롤 리빌

`IntersectionObserver`(threshold 0.12, rootMargin `0px 0px -8% 0px`), 한 번만 실행. 기본 상태 `opacity:0; translateY(22px)`, 진입 시 원위치. transition .8s `cubic-bezier(.22,1,.36,1)`, 형제 요소는 0.08–0.1s씩 지연.
**중요**: 남은 자리 막대와 타임라인 세로선은 시작 상태가 `scale(0)`으로 면적이 0이라 자기 자신을 관찰하면 발화하지 않는다 → **부모 요소를 관찰**하는 별도 옵저버(threshold 0)를 쓴다.

### 그 외

- 버튼 hover: 배경 `#111 → #3a3a3a` + `translateY(-1~2px)`, active `scale(.97~.98)`, transition .25s
- 입력창: hover 테두리 `#c9c7c2`, focus `#111`, `outline:2px solid #111; outline-offset:3px`
- `<details>` 열림: 답변 `answerIn` .38s, `+` 45° 회전
- 앵커 이동: `window.scrollTo({behavior:'smooth'})`, 헤더 높이만큼(-56px) 보정 (`scrollIntoView` 사용 금지)
- `prefers-reduced-motion: reduce`: 모든 애니메이션 비활성 + 인트로 오버레이 `display:none` (반드시 유지 — 안 하면 흰 화면이 남는다)
