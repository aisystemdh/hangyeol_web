# db — 사전등록과 결제 상태

## 왜 있나

이 폴더가 생기기 전, 랜딩 신청 폼은 Formspree로 **메일만** 보냈다. 사전 등록을
받고 있다고 생각했지만 실제로는 아무 데도 쌓이지 않았고, 그래서 「몇 명이
등록했나」·「성비가 어떤가」·「누가 입금했나」를 아무도 알 수 없었다.

## 마이그레이션 돌리는 법

`DATABASE_URL`은 Vercel > Storage에서 Neon을 붙이면 자동으로 생긴다.
로컬로 받아오려면 `npx vercel env pull .env.local`.

**방법 1 — Neon 콘솔 (권장)**
Neon 대시보드 > SQL Editor를 열고 `migrations/` 안의 파일을 **번호 순서대로**
통째로 붙여넣어 실행한다. 결과가 눈에 보여서 처음 한 번은 이 편이 안전하다.

**방법 2 — psql**

```bash
psql "$DATABASE_URL" -f db/migrations/001_applicant.sql
```

## 테스트 DB

테스트는 **표를 통째로 비우며** 돌기 때문에 전용 데이터베이스가 따로 있어야 한다.
같은 Neon 프로젝트 안의 다른 데이터베이스(`hangyeol_test`)를 쓰고 주소는
`.env.local`의 `TEST_DATABASE_URL`에 둔다.

스키마는 **여기 `migrations/`를 그대로 돌려서** 세운다(`vitest`의 준비 단계가
`migrate()`를 부른다). 🔴 테스트용 스키마를 따로 적어 두지 않는다 — 두 벌이 되면
마이그레이션을 더할 때마다 한쪽이 뒤처지고, 테스트는 통과하는데 배포하면 깨진다.

🔴 `TEST_DATABASE_URL`이 없거나 `DATABASE_URL`과 같은 데이터베이스를 가리키면
테스트가 **아예 시작하지 않는다**(`tests/setup/env.ts`). 풀러 주소와 직결 주소는
호스트가 다르지만 같은 곳이므로, 비교할 때 `-pooler`를 떼고 본다.

## 규칙

- **마이그레이션은 고치지 않고 새로 더한다.** 이미 돌아간 파일을 고치면 어느
  환경이 어디까지 적용됐는지 알 수 없게 된다. `002_...sql`을 새로 만든다.
- 모든 문장은 **여러 번 돌려도 안전하게**(`if not exists`, `on conflict do nothing`)
  쓴다. 중간에 실패했을 때 처음부터 다시 돌릴 수 있어야 한다.
- 🔴 **한 파일 안에서는 drop과 create를 쪼개지 않는다.** 실행기가 파일 하나를 한
  트랜잭션으로 돌리므로, 쪼개면 중간에 실패했을 때 **표가 절반만 남는다** — 그 상태가
  가장 고치기 어렵다. `005_rebuild.sql`이 그래서 한 파일이다.
- 스키마의 근거는 **이 저장소**다 — `docs/decisions/003-scenario-redesign-2026-09-05.md` §5,
  말의 뜻은 `CONTEXT.md`. 지식베이스 레포와 옵시디언 볼트는 참조일 뿐이고 어긋나면
  이쪽이 이긴다(2026-09-05 소유자). 컬럼을 바꾸기 전에 그 두 문서를 먼저 본다.

## 되돌리면 깨지는 것 (`005` 안에 주석으로도 있다)

- 🔴 `money.application_id`는 **`on delete set null`**이다. 신원은 3년 뒤 파기한다고
  화면에 고지했고, 결제 기록은 전자상거래법 §6이 **5년 보존**을 요구한다. cascade로
  되돌리면 3년째에 법 위반이 된다. 그래서 `money.event_id`를 따로 들어 연결이 끊긴
  뒤에도 「몇 차 매출인가」가 남는다.
- 🔴 `answer`의 중복 방어는 **부분 UNIQUE 두 개**다. `(신청, 폼, 라운드)` 하나로 합치면
  Postgres가 NULL을 서로 다른 값으로 보아 **새로고침 두 번으로 뚫린다.**
- 🔴 상태는 셋뿐이고 DB 제약으로 못박혀 있다. **대기자는 저장하는 값이 아니다** —
  「자기 성별 입금완료 수가 정원에 닿았는가」를 그때그때 센다.
- 🔴 `applicant`에 **나이 컬럼을 만들지 않는다.** 항상 `birth`에서 계산한다.
- 🔴 `event`(회차) 표에 **정원 숫자를 두지 않는다.** 정원 정본은 `src/lib/event.ts`다.
  단 `event.id`는 그 파일의 `EVENT.id`와 **같은 값이어야 한다.**
