## 5. 돌고 있던 에이전트 · 결과 요약

이번 세션 서브에이전트 8개(전부 완료, 지금 도는 것 없음). 핵심 사실만:

1. **`/me/[token]` 화면 결정** — `GET /api/me/[token]`이 토큰으로 신청 조회 → `resolveMeScreen()`
   (`src/lib/me-screen.ts`)이 상태 5개(status·registered·answered·waitlisted·eventPhase)로 화면
   8종 중 하나를 계산 → 클라이언트가 `switch(data.screen)`. 손님은 URL로 뒤 화면 못 봄.
   `guardExposure()`가 계좌·문항 노출을 재검증. 운영자 `view_override`만 강제 가능.
2. **토큰** — `application.token` 하나. `randomBytes(16).toString("base64url")` (128비트, 22자),
   신청 시 1회 발급, 전 과정 동일. 회차 다르면 새 신청 = 새 토큰. `/me` 라우트에 레이트리밋·형식검증
   없음(128비트 랜덤이 유일 방어선). 만료 없음.
3. **알림톡 링크** — `myPageUrl(token)` = `new URL('/me/'+token, SITE_URL)`. `SITE_URL` =
   `NEXT_PUBLIC_SITE_URL` (현재 `https://hangyeolofficial.kr`). 9개 템플릿 전부 본문 `▶ #{링크}` +
   버튼에 그 사람 링크. 자동발송은 `apply/route.ts:216` (`afterResponse` → `sendTemplate`).
   ⚠️ `docs/alimtalk-templates.md`·테스트는 `hangyeol.kr`로 적혀 있으나 실제 코드·배포는
   `hangyeolofficial.kr`. `8_알림톡`도 "hangyeol.kr/me/<짧은토큰>"을 이상형으로 적음 — 도메인 미확정.
4. **뿌리오 규격(옛)** — `src/lib/alimtalk.ts:130-257`. 참고용. 알리고로 대체됨.
5. **알리고 규격** (공식 `smartsms.aligo.in/alimapi.html`):
   - 발송 `POST https://kakaoapi.aligo.in/akv10/alimtalk/send/`, **form-urlencoded**.
   - 필수: `apikey`, `userid`, `token`, `senderkey`, `tpl_code`, `sender`, `receiver_1`,
     `subject_1`, `message_1`. 버튼 `button_1`(JSON 문자열, `linkType:"WL"`, `linkMo`/`linkPc`).
   - 토큰: `POST /akv10/token/create/{n}/{단위}/` (예 `/1/h/`), 응답 `{code:0, token, urlencode}`.
     최대 유효기간 문서 명시 없음. 캐시 권장.
   - 응답: `{code:0, message, info:{mid, scnt, fcnt}}`. `code===0` = 접수(도달 아님).
   - failover: `failover=Y` + `fsubject_1` + `fmessage_1`. 건당 ~8.4원.
   - `testMode=Y` — 과금·실발송 없이 템플릿 일치 검증.
   - **IP 화이트리스트: 계정 "허용 IP"를 비워두면 제한 없음** → Vercel OK.
   - 브랜드 메시지: `/brandtalk/template/send/`, `kakao_target` M/N/I, 템플릿유형
     TEXT/IMAGE/WIDE/CAROUSEL 등.
6. **브랜드 메시지 vs 알림톡** (`kakaobusiness.gitbook.io`):
   - 알림톡 = 정보성만, 친구추가·수신동의 불필요, 전화번호로 발송. 템플릿 사전심사 필수.
