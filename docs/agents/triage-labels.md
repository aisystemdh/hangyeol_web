# Triage Labels

스킬들은 triage를 **다섯 가지 역할**로만 말한다. 이 파일은 그 역할을 이 저장소가 실제로 쓰는
라벨 문자열로 옮긴 대조표다. 스킬이 역할 이름을 말하면(예: "에이전트가 바로 시작할 수 있는 라벨을 붙여라")
오른쪽 열의 문자열을 쓴다.

| 스킬이 말하는 역할 | 이 저장소의 라벨 | 뜻 |
| --- | --- | --- |
| `needs-triage` | `분류필요` | 소유자가 판단해야 하는 이슈 |
| `needs-info` | `정보대기` | 제출자에게 정보를 더 받아야 함 |
| `ready-for-agent` | `에이전트착수` | 명세가 끝나 에이전트가 바로 시작 가능 |
| `ready-for-human` | `사람작업` | 사람이 직접 구현해야 함 |
| `wontfix` | `wontfix` | 하지 않기로 함 |

⚠️ `wontfix`만 영어인 이유: **저장소에 이미 있는 GitHub 기본 라벨**이다(2026-09-04 `gh label list` 확인).
한국어로 새로 만들면 같은 뜻의 라벨이 둘이 되어 어느 쪽이 진짜인지 알 수 없게 된다.
기존 라벨이 있으면 새로 만들지 않고 재사용한다 — 이 표의 존재 이유가 그것이다.

## 라벨 생성

네 개는 **2026-09-04에 생성 완료**다. 다시 만들지 말 것 — 아래는 실수로 지웠을 때 되살리는 명령이다:

```bash
gh label create "분류필요"     --description "소유자가 판단해야 하는 이슈"           --color "fef2c0"
gh label create "정보대기"     --description "제출자에게 정보를 더 받아야 함"        --color "f9d0c4"
gh label create "에이전트착수" --description "명세가 끝나 에이전트가 바로 시작 가능" --color "0e8a16"
gh label create "사람작업"     --description "사람이 직접 구현해야 함"              --color "1d76db"
```

색은 뜻을 눈으로 구분하려고 골랐다: 판단 대기는 연노랑, 사람 대기는 연주황(둘 다 "멈춰 있음"이라
흐린 색), 착수 가능은 초록, 사람 작업은 파랑(둘 다 "갈 수 있음"이라 진한 색).
기존 `P0`(#d73a4a 빨강)·`P1`·`P2`와 겹치지 않게 뒀다.

이 저장소에 이미 있는 다른 라벨들(`P0`·`P1`·`P2`·`design`·`bug`·`documentation` 등)은
**우선순위와 종류**를 나타내고 triage 역할과 층이 다르다. 서로 대체하지 않고 함께 붙는다.

## 라벨 이름을 바꾸려면

오른쪽 열만 고친다. 단, 이미 이슈에 붙어 있는 라벨은 GitHub에서 `gh label edit <old> --name <new>`로
이름을 바꿔야 붙어 있던 이슈들이 따라온다 — 표만 고치면 스킬이 없는 라벨을 찾는다.
