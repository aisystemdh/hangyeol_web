# /handoff — 세션 핸드오프 문서 작성

## 언제
- 상태줄의 컨텍스트 사용량이 180k 근처일 때(상태줄에 ⚠ handoff 표시)
- 이슈 하나가 끝나 자연스러운 경계일 때
- 사용자가 요청할 때

## 어떻게
1. `docs/handoff/` 에 오늘 날짜 파일을 만든다. 같은 날 두 번째면 `-2` 를 붙인다.
2. 아래 템플릿을 **전부** 채운다. 모르는 항목은 "없음"이라고 적는다. 비워두지 않는다.
3. 돌고 있는 에이전트가 있으면 결과를 기다렸다가 핵심만 §5에 적는다. 에이전트 출력 전문은 넣지 않는다.
4. 파일을 저장한 뒤 사용자에게 "`/clear` 후 새 세션을 여세요. SessionStart 훅이 이 문서를 자동으로 읽습니다."라고 알린다.
5. 커밋은 사용자가 지시할 때만 한다.

## 원칙
- 다음 세션이 **이 문서만 읽고** 첫 행동을 할 수 있어야 한다.
- 사실과 결정만. 추측·감상 금지. 결정에는 근거 한 줄.
- 파일·함수는 `path:line` 으로. 코드 전문은 넣지 않는다.
- 사용자에게 아직 못 물어본 질문은 §6에 그대로 남긴다.

## 템플릿
```markdown
# 핸드오프 YYYY-MM-DD

## 1. 지금 하던 이슈
- 이슈 번호 · 제목 · 브랜치
- 어디까지 됐나 (파일 단위)

## 2. 이번 세션에서 끝난 것
- (커밋 해시 · 한 줄)

## 3. 결정과 근거
- 결정 — 왜

## 4. 아직 안 된 것 · 알려진 문제

## 5. 돌고 있던 에이전트 · 결과 요약

## 6. 사용자에게 물어봐야 할 것

## 7. 다음 세션의 첫 행동 (명령 그대로)
```
